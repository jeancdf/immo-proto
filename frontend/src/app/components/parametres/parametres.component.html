Préférences de sécurité

Définissez vos règles par défaut pour les liens de partage.

Durée par défaut Les liens expirent par défaut après 30 jours. Modifiable à chaque partage.
Protection par code Imposer un code d'accès pour tous les nouveaux partages.
Téléchargement des documents Autoriser le téléchargement hors de DossierHub pour les professionnels de confiance.
Journal des accès Conserver un historique des connexions pendant 24 mois.

Ces préférences sont utilisées par défaut lors du partage d'un dossier.
