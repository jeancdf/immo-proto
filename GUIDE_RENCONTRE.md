# 🎯 Guide d'Animation - Rencontre avec Agents Immobiliers

## ⏱️ Structure de la Rencontre (90 minutes)

### Partie 1 : Questions Pré-Démo (30 min)
**Objectif :** Comprendre leurs besoins sans biais

### Partie 2 : Démo (30 min)
**Objectif :** Présenter les fonctionnalités de manière fluide

### Partie 3 : Questions Post-Démo (30 min)
**Objectif :** Recueillir un feedback structuré

---

## 📋 CHECKLIST AVANT LA RENCONTRE

- [ ] Préparer l'environnement de démo (données de test)
- [ ] Tester tous les parcours utilisateur
- [ ] Imprimer les questionnaires (ou avoir une tablette)
- [ ] Préparer un ordinateur avec la démo
- [ ] Vérifier la connexion internet
- [ ] Préparer des exemples concrets (dossier location, dossier vente)

---

## 🎤 PARTIE 1 : QUESTIONS PRÉ-DÉMO (30 min)

### Objectifs
- Comprendre leur processus actuel
- Identifier leurs points de friction
- Découvrir leurs besoins réels
- Éviter de biaiser avec la démo

### Conseils d'Animation

1. **Commencez par une question ouverte**
   > "Pouvez-vous me décrire une journée type dans votre gestion de dossiers ?"

2. **Écoutez activement**
   - Notez les mots-clés qu'ils utilisent
   - Repérez les frustrations récurrentes
   - Identifiez les tâches répétitives

3. **Approfondissez les réponses**
   - "Pouvez-vous me donner un exemple concret ?"
   - "Combien de temps cela vous prend-il ?"
   - "Quelles sont les conséquences si cela ne fonctionne pas ?"

4. **Ne mentionnez PAS encore la solution**
   - Évitez : "Ah, nous avons justement ça dans notre outil"
   - Préférez : "Je note, c'est intéressant"

### Questions Clés à Poser

**Pour l'agent LOCATION :**
- Comment gérez-vous la collecte des garanties ?
- Comment suivez-vous les visites et les candidatures ?
- Quels sont les documents les plus difficiles à obtenir ?

**Pour l'agent VENTE :**
- Comment coordonnez-vous avec les différents tiers (banque, syndic, notaire) ?
- Comment suivez-vous les délais légaux (rétractation, conditions suspensives) ?
- Quels sont les risques si un délai est manqué ?

### Points à Noter

- [ ] Leurs outils actuels
- [ ] Leurs principales frustrations
- [ ] Leurs besoins prioritaires
- [ ] Leur budget approximatif
- [ ] Leur niveau technique

---

## 🖥️ PARTIE 2 : DÉMO (30 min)

### Objectifs
- Présenter les fonctionnalités de manière fluide
- Montrer la valeur ajoutée
- Adapter le discours selon leurs besoins identifiés

### Structure de la Démo

#### 1. Introduction (2 min)
- Présentation rapide de l'outil
- Vue d'ensemble de l'interface
- Navigation principale

#### 2. Parcours par Scénario (25 min)

**Scénario 1 : Création d'un dossier (5 min)**
- Créer un nouveau dossier
- Ajouter un client
- Sélectionner/créer un bien
- Montrer la checklist automatique

**Scénario 2 : Collecte de documents (5 min)**
- Générer un lien de dépôt
- Montrer le dépôt côté client
- Montrer l'analyse automatique (OCR/AI)
- Vérifier la complétude

**Scénario 3 : Suivi des délais (5 min)**
- Montrer le widget des délais légaux
- Expliquer les alertes
- Montrer comment marquer un délai comme traité

**Scénario 4 : Gestion des biens (5 min)**
- Lister les biens
- Voir les dossiers associés
- Générer une annonce automatique
- Filtrer par type (location/vente)

**Scénario 5 : Dashboard analytique (5 min)**
- Montrer les KPIs
- Expliquer les alertes
- Montrer les tendances

#### 3. Questions/Réponses (3 min)
- Répondre aux questions immédiates
- Noter les points à approfondir

### Conseils pour la Démo

1. **Adaptez le discours**
   - Si agent LOCATION : insister sur la rapidité, les garanties
   - Si agent VENTE : insister sur les délais, la coordination multi-tiers

2. **Utilisez des exemples concrets**
   - "Imaginez que vous avez 10 dossiers en cours..."
   - "Voici comment vous gagneriez 2 heures par jour..."

3. **Montrez la valeur, pas seulement les fonctionnalités**
   - "Cette fonctionnalité vous fait gagner X minutes par dossier"
   - "Vous évitez ainsi les erreurs de type Y"

4. **Soyez honnête sur les limites**
   - "Cette fonctionnalité est en développement"
   - "Nous prévoyons d'ajouter X dans la prochaine version"

5. **Laissez-les interagir si possible**
   - "Voulez-vous essayer de créer un dossier ?"
   - "Avez-vous des questions sur cette partie ?"

### Points à Surveiller

- [ ] Leur niveau d'attention
- [ ] Les questions qu'ils posent
- [ ] Les fonctionnalités qui les intéressent le plus
- [ ] Les fonctionnalités qui les laissent indifférents
- [ ] Les moments où ils semblent perdus

## 💬 PARTIE 3 : QUESTIONS POST-DÉMO (30 min)

### Objectifs
- Recueillir un feedback structuré
- Identifier les fonctionnalités manquantes
- Comprendre leurs priorités
- Évaluer leur intention d'achat

### Conseils d'Animation

1. **Commencez par une question ouverte**
   > "Quelle est votre première impression ?"

2. **Allez du général au spécifique**
   - Impression générale
   - Fonctionnalités principales
   - Fonctionnalités manquantes
   - Priorisation

3. **Demandez des exemples concrets**
   - "Pouvez-vous me donner un exemple de fonctionnalité manquante ?"
   - "Dans quel contexte utiliseriez-vous cette fonctionnalité ?"

4. **Priorisez ensemble**
   - "Si vous deviez choisir 3 fonctionnalités à développer en priorité..."
   - "Qu'est-ce qui est le plus bloquant pour vous ?"

5. **Évaluez l'intention d'achat**
   - "Seriez-vous prêt à utiliser cet outil ?"
   - "À quel prix ?"
   - "Qu'est-ce qui vous empêcherait de l'utiliser ?"

### Questions Clés Post-Démo

**Pour valider la compréhension :**
- "Avez-vous bien compris comment fonctionne X ?"
- "Y a-t-il quelque chose qui vous a surpris ?"

**Pour identifier les manques :**
- "Qu'est-ce qui vous manque le plus ?"
- "Quelle fonctionnalité de votre outil actuel n'avez-vous pas vue ?"

**Pour prioriser :**
- "Si vous deviez choisir 3 fonctionnalités à développer..."
- "Qu'est-ce qui est le plus important pour vous ?"

**Pour évaluer l'intention :**
- "Seriez-vous prêt à utiliser cet outil en production ?"
- "Qu'est-ce qui vous empêcherait de l'utiliser ?"

### Points à Noter

- [ ] Fonctionnalités appréciées
- [ ] Fonctionnalités manquantes
- [ ] Priorités de développement
- [ ] Intention d'achat
- [ ] Budget
- [ ] Prochaines étapes

## 📊 SYNTHÈSE POST-RENCONTRE

### À Faire Immédiatement Après

1. **Rédiger un résumé**
   - Points clés de la rencontre
   - Besoins identifiés
   - Feedback reçu
   - Prochaines étapes

2. **Prioriser les fonctionnalités**
   - Quelles fonctionnalités développer en priorité ?
   - Quelles fonctionnalités améliorer ?

3. **Préparer une proposition**
   - Si l'intention d'achat est positive
   - Adapter selon leurs besoins

4. **Planifier le suivi**
   - Quand les recontacter ?
   - Quoi leur envoyer ?

```
RENCONTRE DU [DATE]
Avec : [Agent 1 - Location] et [Agent 2 - Vente]

BESOINS IDENTIFIÉS :
- [Besoin 1]
- [Besoin 2]
- [Besoin 3]

FEEDBACK SUR LA DÉMO :

- [Point 1]

- [Point 1]
- [Point 2]
```

---

## ⚠️ PIÈGES À ÉVITER

1. **Ne pas écouter assez**
   - Parler trop pendant la partie pré-démo
   - Ne pas noter les besoins réels

2. **Biaiser avec la démo**
   - Mentionner les fonctionnalités avant de comprendre les besoins
   - Forcer les fonctionnalités qui ne correspondent pas

3. **Démo trop technique**
   - Utiliser du jargon
   - Ne pas montrer la valeur ajoutée
   - Aller trop vite

4. **Ne pas recueillir de feedback**
   - Ne pas poser de questions après la démo
   - Ne pas prioriser les fonctionnalités
   - Ne pas évaluer l'intention d'achat

5. **Ne pas faire de suivi**
   - Oublier de remercier
   - Ne pas envoyer de résumé
   - Ne pas planifier de prochaines étapes
